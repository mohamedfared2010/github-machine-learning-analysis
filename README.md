Why is it important to verify data collected from public APIs?

Because public API data may contain missing, incorrect, or outdated information. Checking the data helps make sure that the analysis is based on reliable information.

Why should data analysts document the source of their data?

Data analysts should document the source so other people can understand where the data came from and verify the information if needed. It also makes the project more transparent and trustworthy.

How can missing or inaccurate data affect analysis and decision-making?

Missing or inaccurate data can lead to incorrect results and misleading conclusions. This can cause people or businesses to make poor decisions based on unreliable information.
